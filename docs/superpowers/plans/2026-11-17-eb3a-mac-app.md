# EB3A Monitor (macOS) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Нативний menu bar застосунок для macOS, що тримає BLE-з'єднання з Bluetti EB3A, показує заряд/сонце/прогноз автономності в рядку меню, має поповер з керуванням і графіком та віджет WidgetKit.

**Architecture:** Уся логіка без UI — у локальному Swift package `EB3AKit` (протокол, декодування, прогноз, історія, спільний знімок), тестується `swift test`. Застосунок `EB3AMonitor` (SwiftUI `MenuBarExtra` + CoreBluetooth) і розширення `EB3AWidget` генеруються XcodeGen з `mac/project.yml` і залежать від пакета. Обмін з віджетом — через App Group контейнер.

**Tech Stack:** Swift 6.4, SwiftUI, CoreBluetooth, Swift Charts, WidgetKit, ServiceManagement (`SMAppService`), XCTest, XcodeGen.

**Spec:** `docs/superpowers/specs/2026-11-17-eb3a-mac-app-design.md` (читати разом), карта регістрів `REGISTERS.md`.

## Global Constraints

- Мінімальна macOS: 26.0. Xcode 27.1. Мова інтерфейсу: українська.
- Підпис: безкоштовний Personal Team, `DEVELOPMENT_TEAM = <TEAM_ID>`. App Group: `<TEAM_ID>.eb3a` (без префікса `group.`).
- Bundle ID: застосунок `com.legion.eb3amonitor`, віджет `com.legion.eb3amonitor.widget`.
- `LSUIElement = YES`; `NSBluetoothAlwaysUsageDescription = "Підключення до зарядної станції Bluetti EB3A"`.
- BLE: сервіс `0000FF00-0000-1000-8000-00805F9B34FB`, write `FF02`, notify `FF01`; пристрій за іменем з префіксом `EB3A`.
- Modbus: slave `0x01`, FC03 / FC06, CRC16 Modbus little-endian. Опитування: блоки `(10,53) (70,21) (210,10) (3000,67)`, цикл 2 с, таймаут відповіді 3 с, 3 таймаути поспіль → перепідключення.
- Whitelist запису (і нічого більше): 3007 {0,1}, 3008 {0,1}, 3034 {1,2,3,4}, 3061 {0,1}, 3063 {0,1}, 3064 {1,2,3,4}, 3065 {0,1,2}, 3066 {0,1}. ECO завжди пишеться парою 3063 + 3061 з однаковим значенням.
- Ніколи: запис 3060, 3006, 3015, 3016; будь-яка взаємодія з сервісом `1d14d6ee-fd63-4fa1-bfa4-8f47b42119f0`.
- Прогноз: ємність 268 Wh, коеф. 0.9, EMA вікно 300 с, показ лише при згладженому розряді > 5 W.
- Застарілість: рядок меню — 30 с, віджет — 600 с.
- Віджет: перезавантаження таймлайну при заряд ±1, зміна наявності мережі, сонце ±20 W; не частіше ніж раз на 60 с.
- Історія: хвилинні агрегати, JSON Lines у контейнері App Group, зберігати 7 днів.
- Коментарі в коді мінімальні й короткі (вимога власника).
- Репозиторій зараз не під git. Кроки «Commit» виконувати, лише якщо власник погодив `git init` (питається при старті виконання); інакше пропускати.

## Review Focus

- Mac заснув/прокинувся або станцію вимкнули: рядок меню має показати `🔋 —` після 30 с, а не заморожене число — тест `testStaleStateShowsDash` (Task 4).
- Станція поза зоною тривалий час: перепідключення з наростаючою паузою 1, 2, 4, 8, 16, 30, 30… с, без шквалу спроб — тест `testBackoffSequence` (Task 7).
- Хвіст попереднього кадру (пізній CRC exception) потрапив у новий запит: асемблер нового запиту має його відкинути, а не повернути сміття — тест `testLeadingGarbageIsSkipped` (Task 2).
- Невідоме значення enum (режим заряду 4 Custom, ліхтар 0) не повинно ламати декодування — тест `testUnknownEnumValuesDecode` (Task 3).
- Мережа повернулась / навантаження впало до 0: прогноз зникає, а не показує «~999:00» — тест `testRemainingNilWhenCharging` (Task 4).
- Пошкоджений рядок у файлі історії (обірваний запис при вимкненні) не повинен ламати графік — тест `testCorruptLineSkipped` (Task 5).
